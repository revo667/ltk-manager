## Library

- **Rebuild library** on the **Mod library requires a newer version** page builds a new library
  from the installed mods. Mods stay. Profiles, folders and enabled mods are reset

## Map Preview

- **Visibility** pane beside the **Outliner**: show or hide the map's **Layers** and
  **Controllers**
- **Reset to the map's visibility** returns to the map's defaults
- Skin Preview: a **Map backdrop** has the same list under **Visibility** in the viewport controls

## Atlas UI Editor

- **Components** pane: drag an element onto the canvas or a layer to add it
- **Delete** in an element's menu, or the `Delete` key, removes it

## Settings

- **Settings > Integrations** installs and updates **Ritobin Tools**. Its Explorer menu converts
  between `.bin` and `.rito` files

## Interface

- Pane tabs show their pane's icon, and the **Panes** menu lists each pane with it

### Changed

- Bin Editor: **Show in file** and **Collapse all** are in the menu of the object tab header
- Map Preview: **Visibility layers** is **Layers**
- `game_data.yaml`: `Name: !Class` declares a new object of that class

### Fixed

- Map Preview: variants of the same terrain drawing on top of each other, such as the dragon pits
  and Baron pits of Summoner's Rift
- Bin Editor: bins from League patch 26.21 on PBE failing to open
- Patcher: build failing on a `game_data.yaml` with an empty `entries` module
