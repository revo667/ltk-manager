## Library

### Open mod files from Explorer

- **Windows:** double-click a `.fantome` or `.modpkg` file to install it. LTK Manager comes to the
  front on the Mods page and installs it as if the file was dropped on the window. This works when
  the app is closed, in the tray or open on another page
- Each type has its own icon in Explorer, and LTK Manager is listed in **Open with**
- **Settings > Integrations > Mod files** has the switch **Open mod files with LTK Manager**. It is
  on by default
- LTK Manager takes a type only when no other program opens it. If another program does, the card
  shows **Opens with {program}** and **Choose in Windows** opens the Windows default apps page

### Importing a mod you already have

- Importing an archive that is already in the library installs nothing and shows **Already
  installed**. The file name does not matter
- Importing a newer version of a mod in the library updates that mod, as **Update from file** does.
  The mod keeps its place, its folder and whether each profile enables it. A newer version is the
  same mod name and authors at a higher version
- An older or equal version still installs as a separate mod
- Importing several files lists the updated mods and the ones already in the library in the result

### Champions

- The champion list in **Sort and filter** lists every champion in the game, with portraits. Search
  matches a champion's name or its internal name, so `Wukong` and `MonkeyKing` both find Wukong,
  and mods tagged with either spelling count as one champion
- The **Champions** field when editing a mod is a searchable picker with portraits. Type a name that
  is not a champion and choose **Add "{name}"** to keep it
- Champion pills on mod cards, the mod **Details** tab and Workshop project cards show the
  champion's portrait and the game's name for it
- Champion lists need the League folder set in Settings. Without it, filters list the names your
  mods use, as before

## Workshop

### League client files

- **Open the LCU index** and **Open the LCU WADs** in the command palette (`Ctrl+P`) browse the
  League client's archives, the same way as the game index. Preview and extract work as they do for
  game files
- An LCU file has no **Copy into** a layer and no Find references

### Previews

- Images: SVG, GIF, WebP, BMP and ICO open in the image preview
- Video and audio: WebM, MP4, OGG, WAV and MP3 play in the preview
- Text: JSON, JS, CSS, HTML, Lua, YAML, XML, Markdown and other text files open read-only with
  syntax highlighting. **Wrap** wraps long lines, and `Ctrl+F` searches. JSON opens indented. Turn
  **Format** off to see it as stored. Files over 4 MB show the first 4 MB
- Fonts: OTF and TTF show a sample you can retype, at a size from 12 to 72 px

### Game browser

- **View options** in the tree view has a **Thumbnails** switch, off by default. It shows a picture
  of each texture and image file at a **Row height** from 20 to 64 px, as a square or in its
  **Original** shape
- Trees draw depth guides, as the Bin Editor tree does

### Problems

- Problems checks only the files a pack puts in the package. Files your `.modignore` leaves out are
  not checked and no fix writes them
- New warning **Working file in package**, for a project with no `.modignore`. It lists files such
  as `.psd`, `.blend` or `.fbx` that the game never loads. The fix writes the recommended
  `.modignore`, which leaves them out of the package

### Changed

- The **Champions** field when editing a mod or a Workshop project is a picker, instead of a
  comma-separated list
- Game browser trees no longer tint every row under a selected folder. The depth guide of the
  folder is highlighted instead
