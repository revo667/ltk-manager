## Patcher

- Patcher builds download from LeagueToolkit, so a patcher fix no longer waits for a manager release
- **Settings > Patching > Beta patcher** selects the beta channel

## Library

- **Model** tab on a champion mod shows its skin in the viewport

## Workshop

- **New map project…** for Summoner's Rift, Howling Abyss and Arena: edit the shipped map, a custom map skin, or a custom map skin from geometry

## Map Editor

- Place, move, rotate, scale and snap placeables with a gizmo, and edit their fields in the inspector
- Edit a mesh's transform, materials, layers, quality and culling, with undo
- **Add mesh** imports glTF, GLB, FBX, OBJ and NVR with materials and textures, previewed in the map first
- **Export** the map or the selected meshes to glTF, and **Reimport from file** replaces one mesh in place
- Outliner with collections, kind filters, and drag to a chunk or a controller
- **Lighting** pane, with the sun direction draggable in the viewport
- Visibility controllers and layers

## Particle Editor

- Select several timeline lanes with Ctrl or Shift, then duplicate, copy, delete, solo, mute or drag them together

### Changed

- Bin Editor: **Declare edits** in the toolbar replaces the read-only strip when declarations are off
- Particle Editor: the rig target handle is off at every launch
- Map preview: map particles draw in fewer passes
