## Particle Editor

### Graph

A new **Graph** pane shows every emitter of a particle system as nodes, with a live preview node.
Open it from the **Panes** menu.

- Add a field, force or new emitter from the quick add: `Tab`, `Shift+A`, or a double-click on the
  canvas
- Click or drag a hollow socket to turn a constant into a **Curve** or a **Random range**
- **Duplicate** (`Ctrl+D`) and remove (`Delete`) the selected node, and drop a texture or mesh from
  the content tree onto a node to set it
- Value nodes show the **Value at the playhead**. File nodes preview their texture or mesh
- A new **Geometry** node shows the emitter's live particles over its spawn shape, and plays with
  the timeline. **Change class** on a node's header swaps a primitive or a pointer's class
- Hover an emitter's nodes to show it in the viewport. Hide or solo (`S`) an emitter from its header
- **Show preview in graph** moves the viewport into the graph
- In a declared document, a node shows the layer's icon when that layer declares values in it

### Templates

- Add an emitter from a template: **Glow**, **Sparks**, **Smoke puff**, **Shockwave ring**,
  **Trail** or **Distortion**
- Add a whole system from a template: **Explosion**, **Missile** or **Aura**
- Find them under **Add from template** in the Graph menu and the inspector, or in the Graph quick
  add
- A new `VfxSystemDefinitionData` object in a declared layer can **Start from** a system template
- Templates use only textures the game already ships, so they add no files to the project. They
  are starting points to tune, not finished effects

### Emitters

- **Duplicate emitter** (`Ctrl+D`), **Copy emitter** (`Ctrl+C`), **Paste emitter** (`Ctrl+V`) and
  **Delete emitter** (`Delete`), from the Graph pane or the inspector. A copied emitter pastes into
  another system or file
- Click a particle in the viewport to select its emitter

### Preview rig

The **Rig** control in the viewport now picks how the preview carries a system, from the system
itself.

- **Motion:** **Ground**, **Flight** or **Orbit**, plus **Bone** for an effect on a skin's joint
- **Playback:** **Once**, **Replay** or **Continuous**
- A system that never stops plays **Continuous**, and a system with a trail uses **Orbit**
- Changing a setting makes the rig **Custom**. **Reset to auto** goes back
- **Orbit** carries the system as a missile, so a trail lies along the circle. Set **Orientation**
  to **Unit** for a champion-carried effect, such as a dash

### Open effect

- **Open effect** in a spell's Missile pane opens the missile effect on the spell's own flight and
  speed. A new **Hit effect** row opens the impact effect
- **Open effect** in a skin preview lists its idle effects and the particle events of the playing
  animation. Each opens on its joint, and an event fires at its frame
- `Ctrl` and a click opens the effect in a tab beside the current one

### Timeline

- Drag an emitter's bar to move it, and drag its edges to retime it. Double-click a bar for exact
  times
- Add markers with the **Add marker** button, `Ctrl+M`, or by right-clicking the ruler. Click a
  marker to jump to it, drag it to move it, and double-click it to name it. Markers are saved in the
  project and are not packed into the mod
- New **Snapping** toggle. Scrubbing, loop ranges, markers and bars snap to bar edges, bursts,
  markers, the playhead and ruler ticks. Between them, times round to whole frames

### Inspector

- A **Changes** menu marks changed, added and removed properties, compared with the file as opened
  or with the game's copy. **Changed only** hides the rest. Right-click a row to **Revert to
  opened** or **Revert to game**
- Values have a third mode, **Random between two values**, with random-range lanes in the curve
  editor
- Color fields have a color picker with alpha
- **Reset to default** in a property's right-click menu
- **Show only defined properties** and **Add property** in the action bar
- A **Viewport handle** menu replaces the move and rotate buttons, with handles for offset, turn,
  position, shape size and birth velocity. The velocity handle shows the particle's flight path

### Previews

- Shimmer emitters now play in the preview, and shaders that write a glow target glow. The glow is
  an approximation of the game's
- Planar projection emitters now draw, as decals on the ground
- A texture saved from another program redraws every open preview

## Bin Editor

- A new **Sandbox** button leads every bin tab. It shows whether the tab reads the project or the
  game, and switches the same tab to the other. **Game** opens the installed game's copy read-only
- The declaration options, **Use game data declarations**, **Layer the edits declare into** and
  **Module the edits declare into**, moved into the Sandbox menu
- A row that a layer's `game_data.yaml` overrides at build shows that layer's icon
- Class and field hover cards are redesigned. A class card lists its base classes and counts its
  fields and the game's objects of that class. A field card shows its type, default value, the class
  that declares it, and a warning when the file and the schema disagree on its type
- Flags fields edit from a dropdown with a checkbox for each named bit
- Hash tables a project declares now name the objects a mod adds and `Hash` values, as well as
  file paths

## Map Preview

- Search placeables and filter them by kind in the outliner
- **Placeables** switch and a **Box select** tool in the preview. Selection is shared with the
  outliner, and the selection bar can frame, hide or clear it
- **Event effects** shows effects that appear only during an in-game event. It is off by default

## Workshop

- Editor panes are rounded panels with gaps between them
- Trees, graph nodes and timeline lanes use the regular UI font instead of a monospace font

### Changed

- **Windows:** LTK Manager now installs for all users, under Program Files, and the installer asks
  for administrator rights. It removes an existing per-user install first, and your settings and
  mods stay. Updates also ask for administrator rights from now on
- **Existing projects:** a game bin that one of the project's layers ships now opens as that
  layer's file, and edits save to it. Before, it opened as declarations over the game's copy
- **Existing projects:** a layer with a negative priority now shows the same content as the build
  produces
- The rig presets **Still**, **Burst**, **Missile** and **Trail** are replaced by the **Motion** and
  **Playback** choices. Effects now start on the ground instead of half a champion's height up
- The Timeline's **Loop** toggle switches between **Replay** and **Once**
- "Colour" is spelled "Color" throughout the app

### Fixed

- Particle systems whose custom material is declared in a linked bin, such as the skin or map bin,
  previewing without that material
- A link followed out of a declared document opening undeclared
- Open tabs of a layer losing their file when the layer is renamed

### Known Issues

- Planar projection decals draw on a flat ground, with no terrain or fog of war
