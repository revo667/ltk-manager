## Library

- Change the library while the patcher runs: toggle, reorder, install, update and uninstall mods,
  manage folders, switch profiles
- With a game open, changes wait for the next game, shown by **Applies after this game** beside
  **Play**

## Atlas UI Editor

A new Workshop editor for the game's UI. Open a `ViewController` object in the **View** layout.

- Preview each scene on its own screen, at any resolution and **HUD scale**
- **Sample content** (`S`), **Interact** (`I`), **Button state** (`B`), **Effects** (`E`) and
  **Safe zone** (`Z`)
- Move and resize elements with snapping. **Arrange**, **Align** and **Distribute** from the
  right-click menu
- Edit anchors and scaling in the Inspector's **Position** section
- **Export PNG** and **Replace image** (`R`) for sprites
- **Make surface from this** for 9-slice panels
- **New font from this one**, and import a `.ttf` or `.otf` as a font's face
- Previews of views, UI elements and fonts in the Objects browser
