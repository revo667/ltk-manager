## Library

- Changes that add or remove files in a game archive apply much faster. Turning such a mod on or
  off no longer rebuilds the whole archive: adding one file to a Summoner's Rift mod went from 9-15
  seconds to under half a second
- A `.fantome` mod with layers lists them, and turning a layer on or off changes what loads in game
- **Problems** and **Fix** check every layer of a `.fantome` mod, not only the base layer

## Workshop

### Pack

- **Pack** packs right away, with no dialog. The result shows as a notification, with **Show in
  Explorer**
- The arrow beside **Pack** in the project header chooses **Pack as**: **Both formats**,
  **.modpkg** or **.fantome**. The choice applies to every project, including packing from a card,
  the command palette or a selection
- Packing to `.fantome` keeps every layer. cslol-manager and other Fantome tools load only the base
  layer
- Errors stop a pack with **{name} can't be packed yet**. Warnings are listed on the result and do
  not stop it. Files the ignore rules left out show as **{count} left out**, which opens the ignore
  rules
- Packing a selection checks every project first, then shows one summary: **Packed {packed} of
  {total} projects**

### Test

- The arrow beside **Test** chooses the **Layers to test** in a project with more than one layer.
  **Base** is always tested
- The arrow shows how many layers a test loads, such as `2/3`. The choice is kept per project, and
  testing from a card or a selection uses it too

### Layers

- Layer slugs can contain underscores, such as `item_shop`
- Importing a `.fantome` with layers creates a project layer for each

## Atlas UI Editor

- A new **Tooltip** row above the preview fills a tooltip view with a spell's own tooltip. Choose a
  **Character** and an **Ability**: **Passive**, Q, W, E or R. The tooltip draws while **Sample
  content** is on
- **Level** and **Rank** read the tooltip's values at a champion level and an ability rank. Level 0
  reads every stat as 0
- **Shift** shows the extended tooltip of a spell that has one. Holding `Shift` over the preview in
  **Interact** mode shows it too
- Previews read the game's files with the project's game data declarations applied

## Bin Editor

- The **Sandbox** button shows where edits go: the active layer, and its module when one is chosen
- The Sandbox menu has **Read from**, **Active layer**, **Module** and **Mark changes from**. **Mark
  changes from** chooses whose changes the tree marks, per project
- A row another layer declares shows that layer's icon. Hover it for each layer's value and the
  game's
- Editing a value that a later layer also sets shows **Another layer sets this value**. Make that
  layer the active layer to change it
- An object row's property count follows its class. Number step buttons show on hover

## Home

- A new layout, with **Import** (`Ctrl+I`) and **Play** in the toolbar
- **What's new** shows the notes of the installed version, or of a waiting update with an
  **Update** button. **All release notes** opens the full history
- The RuneForge and RuneForge Wiki links are in the **News** card
- Links in release notes open in the browser

### Changed

- **Pack** writes both `.modpkg` and `.fantome` by default. Choose one format from the arrow beside
  **Pack**
- Packing a selection has no progress bar or **Cancel**
- Bin Editor: **Layer the edits declare into** and **Module the edits declare into** are **Active
  layer** and **Module** in the Sandbox menu. **Use game data declarations** is in the command
  palette
- Bin Editor: a color row shows only its swatch. Edit the channels in the color picker
- New installs use **JetBrains Mono** as the code font. An existing choice stays: change it in
  **Settings > Appearance > Code font**. Ligatures are off in code text

### Fixed

- **Windows:** updating from a version before 1.24.0 removing LTK Manager's shortcuts
- Atlas UI Editor: sliders drawing the thumb and backdrop of every state on top of each other
- Atlas UI Editor: text icons from a sprite atlas not drawing
- Atlas UI Editor: the element inspector not scrolling

### Known Issues

- **Windows:** shortcuts removed by the update to 1.24.0 or 1.24.1 are not recreated, and taskbar
  pins do not carry over to the install under Program Files
- A game archive patched by an earlier version gains the faster updates at its next full rebuild.
  Each patched archive takes about 512 KiB more disk space
